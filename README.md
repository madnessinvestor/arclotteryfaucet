# ArcLotteryFaucet 🎰💧

A **Web3 Faucet + Lottery dApp built on Arc Network**, designed to distribute tokens fairly while gamifying the experience through a lottery-based mechanism.

This project combines a modern frontend, scalable backend, and blockchain integration to create an engaging token distribution platform for testnets, communities, and early adopters.

---

## 🌐 Built on Arc Network

This project is **natively built on top of Arc Network**, leveraging its infrastructure for:
- Fast and low-cost transactions  
- Native support for stable assets like **USDC/EURC (Circle ecosystem)**  
- Smart contract–friendly environment  
- Scalable Web3 application deployment  

ArcLotteryFaucet is designed to be fully compatible with the Arc ecosystem and its tooling.

---

## ✨ Features

- 💧 Token faucet with smart distribution logic  
- 🎲 Lottery-style reward system  
- 🧑‍💻 Web interface for users to claim rewards  
- 🔐 Backend validation and anti-abuse logic  
- 📊 Scalable architecture (API + server + shared modules)  
- ⚙️ Modular codebase for easy expansion  
- 🌍 Ready for community usage and testnet onboarding  

---

## 📁 Project Structure

/api → API layer and external integrations
/client → Frontend application (UI)
/server → Backend logic and services
/script → Utility scripts (automation, deployment, etc.)
/shared → Shared types, utilities and modules


This architecture allows the project to scale cleanly as a production-grade Web3 application.

---

## 🧠 Tech Stack

- **TypeScript** (full project)
- **Node.js** backend
- **Modern frontend stack** (Vite/React style structure)
- Blockchain integration on **Arc Network**
- Environment-based configuration
- Modular monorepo-style structure
